## 구조

인포박스는 본문 흐름을 방해하지 않으면서 사용자가 알아야 할 보조 정보를 강조하는 컴포넌트로, 강조 스타일이 적용된 텍스트 블록으로 구성된다.

```html
<div class="krds-infobox" role="region" aria-label="알림">
  <p class="infobox-text">중요한 안내 사항이 있습니다.</p>
</div>
```

- `.krds-infobox` — 인포박스 컨테이너. `type`·`size` 값이 클래스로 함께 적용된다. `role="region"`과 접근 가능한 이름(`aria-label`)을 갖는다.
- `.infobox-text` — 안내 내용을 담는 본문 텍스트.

| prop | 타입 | 기본값 | 설명 |
|---|---|---|---|
| type | "primary" \| "secondary" | "primary" | 강조 스타일. primary는 기본 강조, secondary는 보조 강조를 나타낸다 |
| size | "default" \| "slim" | "default" | 크기. slim은 좁은 영역에 사용하는 축소형이다 |
| message | ReactNode | — | 안내 내용 (필수) |
| aria-label | string | "알림" | `role="region"`에 제공되는 접근 가능한 이름 |

## 용례

#### 사용하기 적합한 경우

- 본문 내용을 보충하는 부가 정보나 유의사항을 전달할 때
- 신청 절차, 제출 서류 등 사용자가 진행 전에 알아야 할 안내를 제공할 때
- 본문 흐름을 유지하면서 특정 내용을 시각적으로 구분해 강조할 때

#### 사용하기 적합하지 않은 경우

- 사용자 행동의 결과나 오류 상태를 알리는 경우 — 알림(alert) 컴포넌트를 사용해야 한다.
- 긴급하거나 중대한 공지 — 긴급 공지(critical-alerts) 컴포넌트를 사용해야 한다.
- 본문의 핵심 콘텐츠를 대체하거나 인포박스를 여러 개 연속으로 배치하는 경우

## 사용성 가이드라인

**접근 가능한 이름을 제공한다.**
`role="region"`과 함께 `aria-label`을 제공하여 스크린 리더 사용자가 인포박스 영역을 빠르게 탐색하고 건너뛸 수 있도록 한다. `aria-label`은 기본값 "알림" 대신 내용을 짐작할 수 있는 이름으로 지정하는 것을 권장한다.

- KWCAG 2.2 적절한 대체 텍스트 제공
- WCAG 2.1 Info and Relationships (A)

**안내 문구는 간결하고 명확하게 작성한다.**
본문과 중복되는 내용을 반복하지 않고, 사용자가 바로 이해할 수 있는 문장으로 작성한다. 필요한 경우 관련 화면으로 이동하는 링크를 인포박스 안에 함께 제공할 수 있다.

**색상에만 의존해 강조하지 않는다.**
type에 따른 배경·테두리 색상 변화와 함께 텍스트 크기나 아이콘 등 비색상 단서를 함께 사용하여 색각 이상 사용자도 구분할 수 있도록 한다.

- KWCAG 2.2 색에 무관한 콘텐츠 인식
- WCAG 2.1 Use of Color (A)

**명도 대비를 확보한다.**
배경과 텍스트 간 명도 대비를 4.5:1 이상으로 제공한다. 배경색을 사용하는 경우에는 강조된 배경 위 텍스트의 대비도 함께 확인한다.

- KWCAG 2.2 텍스트 콘텐츠의 명도 대비
- WCAG 2.1 Contrast (Minimum) (AA)
