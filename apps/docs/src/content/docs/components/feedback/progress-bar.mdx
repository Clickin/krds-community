## 구조

진행률 표시줄은 완료까지의 진행 정도를 시각적·수치적으로 전달하는 컴포넌트로, 시맨틱한 `<progress>` 요소를 기반으로 한다.

```html
<div class="krds-progress-bar" aria-valuenow="70" aria-valuemax="100" aria-valuemin="0">
  <progress class="krds-progress" value="70" max="100">70%</progress>
  <span class="progress-label">진행률</span>
</div>
```

- `.krds-progress-bar` — 진행률 표시줄 컨테이너. `size`·`state` 값이 클래스로 함께 적용된다.
- `progress.krds-progress` — 진행률을 나타내는 시맨틱 `<progress>` 요소. `value`/`max`로 진행률이 전달되고, 스크린 리더에는 진행률 수치가 읽힌다.
- `.progress-label` — 진행률에 대한 설명 레이블. `label` prop이 있을 때만 렌더된다.

| prop | 타입 | 기본값 | 설명 |
|---|---|---|---|
| size | "large" \| "medium" | "medium" | 진행률 표시줄 크기 |
| state | "active" \| "success" \| "error" | "active" | 진행 상태. active는 진행 중 효과, success/error는 완료 상태의 색상으로 표현된다 |
| value | number | 0 | 현재 진행 값 (0~max) |
| max | number | 100 | 진행 최대 값 |
| label | ReactNode | — | 진행률에 대한 설명 레이블 (선택) |

## 용례

#### 사용하기 적합한 경우

- 파일 업로드·다운로드 등 완료 시점을 예측할 수 있는 작업의 진행 상태를 표시할 때
- 다단계 신청 절차 등 단계별 진행 정도를 사용자에게 안내할 때
- 처리 완료까지 걸리는 시간을 정확히 계산할 수 있는 경우

#### 사용하기 적합하지 않은 경우

- 완료 시점을 예측할 수 없는 대기 상태 — 스피너(spinner)를 사용해야 한다.
- 1초 미만으로 짧게 끝나는 작업에 사용하는 경우
- 정확한 진행률 수치를 계산할 수 없는데 임의의 값을 표시하는 경우

## 사용성 가이드라인

**시맨틱 요소로 진행 상태를 전달한다.**
`<progress>` 요소와 `value`/`max` 속성을 사용하여 스크린 리더 사용자가 진행률 수치를 인지할 수 있도록 한다. 시각적 막대만 제공하고 수치를 함께 전달하지 않으면 진행 상태를 알 수 없다.

- KWCAG 2.2 적절한 대체 텍스트 제공
- WCAG 2.1 Info and Relationships (A)

**접근 가능한 이름을 제공한다.**
`label` prop으로 진행률의 대상이 무엇인지 설명을 제공한다. 레이블이 없으면 스크린 리더 사용자는 어떤 작업의 진행률인지 알 수 없다.

**상태를 색상에만 의존해 전달하지 않는다.**
state에 따른 색상 변화(active/success/error)와 함께 진행률 수치와 레이블을 제공하여 색각 이상 사용자도 상태를 구분할 수 있도록 한다.

- KWCAG 2.2 색에 무관한 콘텐츠 인식
- WCAG 2.1 Use of Color (A)

**진행률은 실제 값을 반영한다.**
표시되는 수치는 실제 진행 정도를 반영해야 한다. 완료 후에는 success 상태로 전환하거나 진행률 표시줄을 제거하여 작업 완료를 명확히 전달한다.
