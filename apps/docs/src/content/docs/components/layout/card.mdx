## 구조

카드는 이미지, 제목, 설명, 배지, 행동 버튼을 하나의 콘텐츠 단위로 묶어 보여주는 컴포넌트로, 목록형 콘텐츠를 일관된 형태로 제공한다.

```html
<article class="krds-card">
  <div class="card-top">
    <img class="card-image" src="/images/example.png" alt="" />
    <div class="card-badge">
      <span class="krds-badge">새소식</span>
    </div>
  </div>
  <div class="card-conts">
    <h3 class="card-title">카드 제목</h3>
    <p class="card-description">카드 설명</p>
    <div class="card-actions">
      <button type="button" class="krds-btn small primary">자세히 보기</button>
    </div>
  </div>
</article>
```

- `article.krds-card` — 카드 컨테이너. `type` 값이 클래스로 함께 적용된다. 시맨틱한 `article` 요소로 렌더된다.
- `.card-top` — 이미지·배지·체크박스 영역. 해당 요소가 있을 때만 렌더된다.
- `.card-image` — `image` prop으로 전달되는 이미지. `imageAlt` prop으로 대체 텍스트를 제공한다.
- `.card-badge` — `badges` prop의 항목이 배지(badge) 컴포넌트로 렌더되는 영역.
- `.card-conts` — 콘텐츠 영역. `h3.card-title`(제목), `.card-description`(설명, 선택), `.card-actions`(행동 버튼, 선택)로 구성된다.

| prop | 타입 | 기본값 | 설명 |
|---|---|---|---|
| type | "vertical" \| "horizontal" | "vertical" | 카드 레이아웃. horizontal은 이미지와 콘텐츠를 가로로 배치한다 |
| image | string | — | 카드 상단 이미지 URL (선택) |
| imageAlt | string | "" | 이미지 대체 텍스트 (선택) |
| title | ReactNode | — | 카드 제목 (필수) |
| description | ReactNode | — | 카드 설명 (선택) |
| badges | string[] | — | 카드에 표시할 배지 텍스트 목록 (선택) |
| actions | `{ label: string; onClick?: () => void }[]` | — | 카드 행동 버튼 목록 (선택) |
| checkbox | CheckboxProps | — | 카드 상단에 표시할 체크박스 (선택) |

## 용례

#### 사용하기 적합한 경우

- 새소식·공지·자료실 등 목록형 콘텐츠를 요약해 제공할 때
- 이미지와 함께 콘텐츠의 성격을 직관적으로 전달하고 싶을 때
- 카드별로 이동·다운로드 등 행동 버튼을 함께 제공해야 할 때

#### 사용하기 적합하지 않은 경우

- 비교·선택을 위한 상세 정보가 많은 경우 — 표(table)나 구조화 목록(structured list)을 사용해야 한다.
- 설명이 길어 카드 안에 담기 어려운 콘텐츠의 경우
- 단순한 링크 나열 — 링크(link)나 텍스트 목록(text list)을 사용하는 것이 적합하다.

## 사용성 가이드라인

**시맨틱한 구조를 제공한다.**
카드는 `article` 요소로 렌더하고 제목은 `h3`으로 제공하여 스크린 리더 사용자가 문서 구조를 통해 카드 콘텐츠를 탐색할 수 있도록 한다.

- KWCAG 2.2 적절한 대체 텍스트 제공
- WCAG 2.1 Info and Relationships (A)

**이미지에 대체 텍스트를 제공한다.**
의미 있는 이미지는 `imageAlt`로 대체 텍스트를 제공하고, 장식용 이미지는 빈 대체 텍스트("")로 처리하여 스크린 리더에 중복 정보가 전달되지 않게 한다.

**카드의 용도를 접근 가능한 이름으로 전달한다.**
제목·배지·행동 버튼의 텍스트는 카드 내용을 짐작할 수 있도록 명확하게 작성한다. 버튼은 "자세히 보기"처럼 단독으로도 용도를 알 수 있는 라벨을 제공한다.

**행동 버튼과 클릭 영역을 충분히 크게 제공한다.**
모바일 환경에서도 조작하기 쉽도록 행동 버튼의 크기와 간격을 확보하고, 카드 전체가 링크인 경우에는 포커스 영역이 카드 전체에 적용되도록 한다.
