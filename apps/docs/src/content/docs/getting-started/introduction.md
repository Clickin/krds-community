KRDS Community는 공식 KRDS HTML Component Kit와 디자인 토큰을 기준으로 React, Vue, Svelte, SolidJS, Angular, Astro용 컴포넌트를 만드는 오픈소스 커뮤니티 프로젝트입니다. 정부의 공식 구현이 아니며, 공식 자료를 대체하지 않습니다.

## 우리가 만드는 것

- 각 프레임워크의 상태·이벤트·폼·SSR 모델을 따르는 네이티브 컴포넌트
- 공식 디자인 토큰에서 생성한 공통 CSS 변수와 Tailwind CSS 테마
- 원본 UI·고정 fixture 기준으로 프레임워크 간 동일한 출력을 검증하는 내부 conformance 테스트
- 구현한 컴포넌트로 구성한 컴포넌트·기본 패턴·서비스 패턴 쇼케이스

Web Components 위에 프레임워크 래퍼를 쌓지 않습니다. 공유 패키지는 토큰, 스타일, class recipe, 검증 계약만 소유하고 DOM과 상태는 각 프레임워크 패키지가 직접 구현합니다.

## 공식 자료와의 관계

컴포넌트의 의미, 상태, 접근성 요구사항은 [공식 KRDS](https://www.krds.go.kr/)가 기준입니다. 이 문서는 공식 디자인 원칙을 다시 요약해 독자적인 규칙처럼 제시하지 않습니다. 디자인 스타일과 상세 사용 지침은 [공식 가이드라인 검토](../../guides/krds-guidelines/)에서 원문 링크를 따라 확인하고, 이 사이트에서는 실제 커뮤니티 패키지의 API와 동작을 검토합니다.

공식 source와 구현이 다르면 차이를 숨기거나 스냅샷 임계값으로 무시하지 않습니다. 고정 upstream fixture를 보존하고, 근거와 적용 범위를 errata 및 conformance 계약에 기록합니다.

## 라이선스와 출처

공식 KRDS 자료의 KOGL 제1유형 출처 표시를 보존합니다. 커뮤니티가 작성한 원본 코드는 Apache-2.0으로 배포합니다. 패키지와 문서를 사용할 때는 각 source의 `NOTICE`, 공식 저작권 정책, 패키지별 라이선스를 함께 확인하세요.

다음 단계는 [빠른 시작](../installation/)에서 프레임워크 패키지와 토큰 기반 스타일을 설치하는 것입니다.
