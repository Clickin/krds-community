## 공식 문서

오류는 사용자가 요청한 작업을 시스템이 완료하지 못하는 문제가 발생했을 때 제공된다. 발생 가능한 문제를 사전에 안내하는 경고와는 달리, 오류는 이미 발생한 문제에 관한 정보를 사용자에게 알려준다. 오류 정보는 단순히 사용자에게 문제가 발생했음을 알려주는 데 그치지 않고 본래 수행하고자 했던 행동을 완수할 수 있게 유도해야 한다. 오류 정보를 제공하기 위해 별도의 모달을 사용하거나 오류가 발생한 지점에 직접 메시지를 전달할 수 있다.

### 유형

**인라인 메시지** 오류가 발생한 입력 요소 바로 아래에 메시지를 표시하여 사용자가 오류가 발생한 지점을 즉시 파악하고 수정할 수 있도록 한다.

**모달** 오류가 발생한 경우 별도의 모달을 사용하여 사용자에게 오류 정보를 안내한다. 모달을 사용할 때는 오류를 안내한 후 사용자가 본래 수행하던 과업으로 자연스럽게 돌아갈 수 있도록 유도해야 한다.

## 사용성 가이드라인

### 오류

**빠르게 인지할 수 있도록 표현한다.**
오류 메시지의 크기, 색상, 위치 등은 사용자가 빠르게 오류 발생 정보를 인지할 수 있게 표현해야 한다.

**발생한 오류 및 문제를 분명하게 설명한다.**
사용자가 어떤 종류의 오류가 어떤 지점에서 발생했는지 명확히 이해할 수 있어야 오류를 수정할 수 있다.

**오류를 수정할 수 있는 방법을 제공한다.**
오류의 내용이 복잡한 경우, 문제를 수정할 수 있는 방법을 함께 제공하면 효과적으로 오류를 수정할 수 있다.

**정중한 문체를 사용한다.**
오류 메시지는 사용자에게 부정적인 상황을 알려주는 정보이므로, 정중한 문체를 사용하여 사용자를 안심시켜야 한다.
