title: 기본 패턴
description: 컴포넌트가 조합되어 반복적으로 사용되는 공통 과업 패턴입니다.
---

기본 패턴은 개인 식별 정보 입력부터 모바일 설정까지 공통 과업의 구조와 접근성 확인 지점을 다룹니다. 공식 기본 패턴 페이지에는 서비스 패턴과 같은 적용 수준 필터가 별도로 제공되지 않는 경우가 있으므로, 각 상세 페이지에 그 사실을 그대로 표시합니다.
