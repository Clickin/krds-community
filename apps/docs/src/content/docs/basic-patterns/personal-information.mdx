## 공식 문서

### 유형

**이름** 이름은 일반적으로 하나의 텍스트 입력 필드로 제공되며, 모든 사용자의 이름 형식을 수용할 수 있도록 구성한다.

**생년월일** 생년월일은 사용자가 이미 알고 있는 날짜이므로 날짜 선택기 대신 날짜 입력 서식에 맞추어 연도, 월, 일을 직접 입력받는다.

**성별** 성별은 라디오 버튼으로 제공되며 특정 성별이 기본값으로 지정되지 않아야 한다.

**전화번호** 전화번호는 활용 용도에 적합한 유형(휴대 전화번호, 지역 번호 등)을 명확한 레이블과 함께 입력받는다.

## 사용성 가이드라인

### 개인 식별 정보 입력

#### 공통

**개인 식별 정보의 수집이 필요한지 확인한다.** 사용자에게 개인 식별 정보의 입력을 요청하기 전에 서비스 이용을 위해 필요한 정보인지 다시 한 번 확인해야 한다.

**입력이 필요한 데이터의 용도를 명확하게 설명한다.** 입력한 데이터가 어떻게 활용될 것이고, 어떤 편의성을 제공할 수 있는지를 사용자에게 명확하게 안내해야 한다.

**개인 식별 정보 입력 필드에 복사와 붙여넣기를 허용한다.** 데이터 입력에 어려움을 느끼거나 시간이 많이 걸리는 사용자를 고려하여 모든 개인 식별 정보 입력 필드에는 복사와 붙여넣기를 제한하지 않아야 한다.

**기본값을 설정하지 않는다.** 플레이스홀더를 사용하는 경우에는 실제 입력과 쉽게 구분할 수 있도록 한다.

#### 이름

**사용자가 입력할 수 있는 모든 문자의 입력과 표시를 지원한다.** 사용자의 이름이 다양한 언어로 작성될 수 있음을 고려하여 기호, 공백을 포함한 모든 문자를 입력 가능하도록 허용하고 화면에 적절히 표시될 수 있도록 해야 한다. 만약 본인인증 과정 등 문서에 표시된 이름의 문자 형식이 지정되어 있고 해당 형식에 따라 정확하게 입력되어야 하는 과업이라면 제약 사항에 대해 사용자에게 명확하게 설명하고, 적절한 경우 대안을 제시해야 한다.

**이름 입력 필드에 입력 가능한 글자 수를 적절하게 구성한다.** 이름 입력 필드는 모든 사용자의 이름을 수용할 수 있는 정도의 글자 수 입력을 허용하고 최대 길이에 맞추어 입력 필드의 너비를 제공한다. 이때, 가장 짧은 이름의 글자 수 역시 고려되어야 한다. 한글 이름을 기준으로 하였을 때 유효성 검사에서 최소 3글자 이상의 입력을 요청하지 않도록 유의한다.

**외국인 사용자 이름의 길이를 고려하여 이름 입력 필드의 가로 길이(field length)를 충분히 확보한다.** 일반 단일 입력 필드 기준 최소 320~360px 이상을 확보하고, 폼이 단일열일 경우 가용 폭을 100% 사용하도록 한다. 이름이 길어도 필드 안에서는 스크롤되거나 전체가 보이도록 처리해 사용자가 내용을 확인할 수 있게 한다.

**사용자가 공백을 포함한 이름을 입력하도록 허용한다.** 클라이언트 및 서버 측 유효성 검사 시 중간 공백을 오류로 처리하거나 자동 제거하지 않으며, “여권에 표기된 이름 전체를 입력하세요. 공백과 ‘-’를 포함할 수 있습니다.”와 같은 안내 문구를 제공하여 입력 오류를 예방한다.

**이름의 대소문자를 정규화하지 않는다.** 여권, 외국인등록증 등 공적 문서와의 일치성을 보장하기 위하여 이름 입력 필드에 대해서는 사용자가 입력한 대·소문자 표기를 그대로 저장하고 표시한다.

#### 생년월일

**생년월일의 입력에 날짜 선택기를 사용하지 않는다.** 날짜 선택기는 사용자가 데이터를 입력하는 시점을 기준으로 전·후의 날짜를 상대적으로 탐색해야 하기 때문에 사용자가 이미 명확하게 알고 있는 날짜를 선택하는 데 적합하지 않다.

**여러 가지 입력 형식에 유연한 입력 필드를 제공한다.** 공백, 하이픈, 대시 등 일반적으로 전화번호의 입력 형식으로 사용되는 다양한 형식의 입력을 허용하여 사용자가 익숙한 방식으로 전화번호를 입력할 수 있도록 한다. 하이픈을 반드시 포함해야 하는 등 특정 형식에 맞추어 입력이 필요한 경우, 도움말 텍스트로 입력 형식의 제한에 대해 명확하게 설명해야 한다. 사용자의 편의성을 위해 자동으로 형식을 수정할 수 있다.

**국가 코드 입력에 콤보박스를 사용한다.** 국가 코드를 기억하지 못하는 사용자의 입력을 돕기 위해 국가명과 국가 코드가 명시된 목록을 콤보박스의 옵션으로 제공한다.

**여러 개의 전화번호 입력 요청 시, 각 번호를 구분할 수 있는 레이블을 제공한다.** 사용자에게 여러 개의 전화번호를 입력할 것을 요청하는 경우, 전화번호 입력 필드 레이블이나 필드셋의 제목으로 각 번호를 명확하게 구분할 수 있는 레이블을 제공하여 사용자가 혼동을 느끼지 않도록 해야 한다. 예) ‘휴대 전화번호’, ‘사무실 전화번호’

**여러 개의 전화번호 입력 요청 시, 주로 사용하는 번호를 지정할 수 있는 옵션을 제공한다.** 사용자가 입력한 번호를 연락 수단으로 사용하고자 하는 경우, 사용자가 어떤 수단을 통해 연락을 받을 것인지, 주로 사용하는 번호가 무엇인지를 선택할 수 있는 옵션을 제공하여 연락을 놓치지 않도록 해야 한다.
