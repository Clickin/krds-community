이 사이트의 구현과 예시는 공식 KRDS 원문과 고정된 HTML Component Kit를 기준으로 관리합니다. 이 프로젝트는 정부의 공식 구현이 아니며, 공식 자료의 출처와 라이선스 고지를 보존합니다.

## 이 사이트에서 확인할 수 있는 것

- 서비스 패턴 5개와 기본 패턴 13개의 한국어 설명
- 각 패턴의 공식 개요·단계·체크리스트 링크와 적용 수준 표기
- 핵심 컴포넌트 API 페이지의 props/events/forms/a11y 안내와 여섯 프레임워크 복사 예제
- 같은 패턴을 여섯 프레임워크의 독립 런타임으로 렌더링하는 실행 예시
- 실제 소스 파일과 키보드·폼·상태 변화를 확인할 수 있는 미리보기

공식 원문을 수정하거나 대체하지 않고, 커뮤니티 구현의 차이와 검증 범위를 명시합니다. 라이브 KRDS 사이트가 고정된 HTML Component Kit snapshot보다 새롭거나 넓은 경우에는 해당 버전 경계를 문서에 표시합니다.
